# Function to build coloumn marginal statistics and Fisher test

Function to build coloumn marginal statistics and Fisher test

## Usage

``` r
LL_fisher_gt_flex(data, row_var, col_var, label_row_var, label_col_var)
```

## Arguments

- data:

  dataframe

- row_var:

  row variable

- col_var:

  column variable

- label_row_var:

  label for row

- label_col_var:

  label for column
