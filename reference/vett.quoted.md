# Funzione che permette partendo da un vettore, di riscrivere quel vettore in varie forme

Funzione che permette partendo da un vettore, di riscrivere quel vettore
in varie forme

## Usage

``` r
vett.quoted(vettore, sym = ", ", quote = T)
```

## Arguments

- vettore:

  Starting vector

- sym:

  Symbol of separation (Default ", ")

- quote:

  Vector elements to be quoted or not (Default = T)

## Value

Una stringa di elementi formattati al meglio
