# Function to print the output of the AIM function with Biomarker, Direction and Cutoff as a data frame model

Function to print the output of the AIM function with Biomarker,
Direction and Cutoff as a data frame model

## Usage

``` r
output.aim.f(res.index, aim.data)
```

## Arguments

- res.index:

  An output from the AIM package function

- aim.data:

  Data where the function was run on

## Value

A dataframe-like object
