# This function returns the filename to be outputted

This function returns the filename to be outputted

## Usage

``` r
filename_LB(
  filename = "Prova",
  extention = ".png",
  output = path_output,
  datetime = F
)
```

## Arguments

- filename:

  name of the file

- extention:

  file extention

- output:

  the main output path

- datetime:

  whether to print the datetime in a cute format
